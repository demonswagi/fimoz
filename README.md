error_logger - предназначен для фиксирования ошибок программы и их записи в текстовый файл. записывает ошибки в файл errors.log
eval_expression - отвечает за арифметические действия. использует +, -, / и *. работает с error_logger

input_handler - отвечает за текстовое наполнение программы. все запросы, выводы текста и предупреждения

output_handler - отвечает за само высчитывание. проивзодит математические расчёты и отправляет их на вывод

main - главный рабочий файл, с которого и происходит запуск программы. главный интерфейс и окно работы
